## 三类 HTTP 接口

### 1. 列表（隐藏 JSON 接口，关键）

```
GET https://hbj.huzhou.gov.cn/api-gateway/jpaas-publish-server/front/page/build/unit
```

查询参数：`pageSize`、`siteId`、`pageId`、`tagId`、`unitId`（= 栏目 colId）

> **这是整个项目能上 Cloudflare Worker 的前提。** 列表页本身是 JS 渲染的，但这个后端接口是纯 HTTP JSON，不需要浏览器。详见 [`02-技术决策.md`](02-技术决策.md)。

**tagId 坑**：绝大多数栏目用 `tagId=zw`，但栏目 `1229858680` 用 `zw` 返回 0 条，必须用 `tagId=list`。两个脚本都用 `ALT_TAGS = ('zw','list')` 做回退。

### 2. 详情页

```
GET https://hbj.huzhou.gov.cn/col/col<colId>/art/<year>/art_<art_id>.html
```

HTML 里有正文、摘要和一个 `<table>`（项目表格）。表格需要特殊处理：**colspan 展开**（有的单元格跨列），并按表头映射列：

| 表头原文 | 映射字段 |
|---|---|
| 项目名称 | name |
| 建设地点 | loc |
| 建设单位 | org |
| 环评机构 | inst |
| 受理日期 | date |
| 环评文件 | 附件 |

### 3. 附件下载网关

```
GET https://hbj.huzhou.gov.cn/api-gateway/jpaas-web-server/front/document/download
    ?fileUrl=<服务端加密的密文>&fileName=<URL 编码的文件名>
```

`fileUrl` **不可离线推算**（base64 解开是 128 字节密文），必须跟随重定向才能拿到 OSS 直链。详见 [`04-附件下载.md`](04-附件下载.md)。

## 数据清洗规则

详情页文本里有大量排版空格（数字与数字、数字与中文之间），统一清掉：

```python
s = re.sub(r"(?<=\d)\s+(?=\d)", "", s)                       # 数字之间
s = re.sub(r"(?<=\d)\s+(?=[\u4e00-\u9fa5])", "", s)          # 数字-中文之间
s = re.sub(r"(?<=[\u4e00-\u9fa5])\s+(?=\d)", "", s)          # 中文-数字之间
```
